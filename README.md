# Задание 1

## Заполнение двумерных массивов

### Текст задачи

1. Первый массив, размерностью n на m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по строкам от первых элементов строки к последним.
2. Второй массив, размерностью n на n, заполняется так: элементы, лежащие выше побочной диагонали, являются случайными числами из интервала [-65; 120], а лежащие на побочной диагонали и ниже, являются случайными числами из интервала [-3.5; 10.75].
3. Третий массив, размерностью n на n, заполняется для произвольного n так же, как для n=5 по заданному образцу (заполнение «змейкой» по диагоналям, параллельным побочной).

### Алгоритм решения

Создается класс `Array` с закрытым полем `_matrix` (двумерный массив). В классе реализованы методы заполнения:

- Метод `FillFromKeyboard()` считывает данные из переданного двумерного массива по строкам слева направо (i от 0 до n-1, j от 0 до m-1).
- Метод `FillBySideDiagonalCondition()` перебирает элементы матрицы: если элемент находится выше побочной диагонали (i + j < n - 1), генерируется случайное целое число из [-65; 120]. Иначе генерируется случайное число из [-3.5; 10.75] с округлением в меньшую сторону.
- Метод `FillThirdArrayVariant4()` реализует алгоритм заполнения матрицы числами по диагоналям («змейкой»), меняя направление обхода (вверх-вправо / вниз-влево) в зависимости от четности индекса диагонали.

Для корректного вывода матрицы переопределяется метод `ToString()`.

# Задание 2

## Работа с двумерными массивами

### Текст задачи

В городе П. есть m банков. Известны величины задолженностей банков друг другу. Укажите банк с максимальным долгом.

### Алгоритм решения

В классе `Array` реализован метод `GetBankWithMaxDebt()`. Алгоритм построчно суммирует элементы матрицы задолженностей (сумма всех j при фиксированной строке i). Индекс строки с наибольшей суммой соответствует номеру банка с максимальным суммарным долгом.

# Задание 3

## Работа с двумерными массивами как с матрицами

### Текст задачи

Перегрузить необходимые операторы и посчитать значение матричного выражения. Перегрузить метод `ToString()` — сформировать строку из двумерного массива для отображения его на экране в виде таблицы. Приложить в отчет скриншот проверки на онлайн-калькуляторе, чтобы показать, что выражение посчитано верно.
Формула для варианта 4: 2 * A - B^T * C.

### Алгоритм решения

В классе `Array` через ключевое слово `operator` перегружаются бинарные операторы вычитания `-`, умножения матрицы на скалярное число `*` и умножения матриц `*`. Также реализуется метод `Transpose()` для транспонирования матрицы.
В основном меню инициализируются матрицы A, B и C, после чего выражение вычисляется в коде через перегруженные операторы: `2 * matrixA - matrixB.Transpose() * matrixC`.

# Задание 4

## Бинарные файлы

### Текст задачи

Бинарные файлы содержат числовые данные. Исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом.
Задача: Подсчитать количество пар противоположных чисел среди компонент исходного файла.

### Алгоритм решения

В статическом классе `BinaryTask` создается метод записи данных `WriteUserBinaryFile` с использованием `BinaryWriter`.
Метод `CountOppositePairs` считывает элементы бинарного файла с помощью `BinaryReader` в массив чисел. В двойном цикле ищется количество пар противоположных чисел (a_i + a_j = 0 при a_i ≠ 0). Для предотвращения повторного учета элементов используется вспомогательный булев массив `counted[]`.

# Задание 5

## Бинарные файлы и структуры (XML-сериализация)

### Текст задачи

Информация о багаже пассажира описывается массивом, где каждый элемент содержит название единицы багажа (чемодан, сумка, коробка и т.д.) и ее массу. Дан файл, содержащий сведения о багаже нескольких пассажиров. На сколько багаж максимальной массы отличается от багажа минимальной массы?

### Алгоритм решения

Определяются структуры `BaggageItem` (название и вес предмета) и `PassengerBaggage` (ФИО пассажира и массив элементов багажа).
Создается метод записи массива структур в бинарный файл (`WriteBaggageBinaryFile`) и метод чтения (`ReadBaggageBinaryFile`).
Метод `CalculateBaggageDifference()` выгружает данные из файла, находит максимальную `maxWeight` и минимальную `minWeight` массы вещей среди всех пассажиров и вычисляет их разность (`maxWeight - minWeight`).
